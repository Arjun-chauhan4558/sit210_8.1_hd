# SIT210 Task 8.1HD – Audio Processing

## Overview
This project explores audio processing and voice command recognition using a Raspberry Pi and Arduino Nano 33 IoT.

## Hardware
- Raspberry Pi
- Arduino Nano 33 IoT
- DHT22 temperature and humidity sensor
- BH1750 light sensor
- Microphone or audio input hardware

## Features
- Voice command recognition
- Sensor data collection
- Communication between the Raspberry Pi and Arduino
- Audio processing and command execution

## Technologies
- Python
- Arduino C++
- Raspberry Pi
- Arduino IDE
